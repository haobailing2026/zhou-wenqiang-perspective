# 周文强 · 思维操作系统（zhou-wenqiang-perspective）

> 「你永远赚不到超出你认知范围外的钱，除非你靠运气；但你靠运气赚来的钱，最后往往又会靠实力亏掉。」

一个用「周文强」的思维框架与表达方式做**思维顾问**的 AI Skill。基于著作、课程体系、演讲/访谈逐字稿、权威媒体批评报道与完整人生时间线的深度调研，提炼出 **7 个核心心智模型、8 条决策启发式和完整的表达 DNA**。

它不是要你模仿周文强，而是让你**多一副看财富、创业、认知问题的眼镜**。

---

## ⚠️ 重要声明（必读）

周文强是**争议极大**的公众人物：其「1 元引流 → 68 万高价课」的商业模式已被澎湃新闻、南方周末等权威媒体调查批评，黑猫投诉平台累计上千条维权记录。

因此本 Skill 的原则是：

- **只还原其「思维框架」，不为其商业模式背书，也不美化争议**
- **涉及具体投资、理财、借贷、付费报课时，输出是「框架推演」，绝不构成投资建议**
- **「梭哈」「博一博单车变摩托」等激进话术已被点名批评，Skill 内置风险红线，不鼓励无脑 All in**

请辩证使用。

## 核心心智模型

| # | 模型 | 一句话 |
|---|------|--------|
| 1 | 穷人思维 vs 富人思维 | 人和人的差距在认知，不在钱多钱少 |
| 2 | ESBI 四象限 | 只有 B、I 象限才有被动收入、才能财富自由 |
| 3 | 道法术器 | 一切都能用「规律/战略/方法/工具」四层去看 |
| 4 | 转念与觉醒 | 得不到想要的，就是即将得到更好的 |
| 5 | 投资大脑 | 花钱买认知、换圈子，是最便宜的翻身路径 |
| 6 | 先舍后得 | 舍在前得在后，发心利他，钱是结果 |
| 7 | 傻信干 | 成功三特质：赤子之心、百分百相信、大量行动 |

> 每个模型都附「证据」「应用」「局限」，其中局限是重点——例如「穷人/富人思维」会忽略结构性贫困，「傻信干」是服从式学习、「投资大脑」正是卖课闭环的理论基础。

## 调研方法论

本 Skill 由「[女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill)」驱动生成，采用 6 维度并行调研：

1. **著作**（书籍、课程体系、核心论点）
2. **对话**（演讲、访谈、直播的即兴表达与应对质疑方式）
3. **表达 DNA**（口头禅、高频词、争议原话、确定性）
4. **他者视角**（媒体批评、学员投诉、同行对比）
5. **决策记录**（14 个关键决策、言行一致/不一致案例）
6. **时间线**（1987–2026 完整轨迹 + 最近 12 个月动态）

所有调研材料严格区分「他说过的 / 别人说他的 / 我推断的」，并规避低质信息源。
